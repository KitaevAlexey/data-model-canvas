# Data Model Canvas

Интерактивный инструмент для визуального проектирования, анализа и документирования моделей данных. Создавайте ER-диаграммы из файлов (S2T, Excel, CSV), редактируйте их на интерактивном холсте и экспортируйте в SQL, S2T, PNG или AI-промпты.

**Живое демо:** [kitaevalexey.github.io/data-model-canvas](https://kitaevalexey.github.io/data-model-canvas)  
**Репозиторий:** [github.com/KitaevAlexey/data-model-canvas](https://github.com/KitaevAlexey/data-model-canvas)

## Для кого

- **Аналитики DWH / BI** — аудит моделей данных as-is и проектирование to-be.
- **Архитекторы данных** — быстрая валидация схем перед передачей в разработку.
- **Консультанты** — проведение воркшопов с живым прототипированием.

## Возможности

### 📥 Импорт моделей
- **S2T** — текстовый формат описания схемы БД.
- **Excel** (.xlsx) — поддержка двух форматов: один лист на таблицу или все таблицы на одном листе.
- **CSV** — все таблицы в одном файле.

### 🗂 Умные вкладки и компоновка
- **Автоматическая разбивка:** приложение находит таблицы фактов и создает для каждой отдельную вкладку (плюс вкладка «Обзор»).
- **Независимые раскладки:** каждая вкладка запоминает свое расположение таблиц и изгибы связей. Изменения на одной вкладке не ломают вид другой.
- **Умный авто-layout:** радиальный алгоритм для звездных схем (факт в центре) и иерархический алгоритм (ELK) для режима «Обзор».

### 🎨 Редактирование и визуализация
- Перетаскивание таблиц по холсту, масштабирование, миникарта.
- **4 точки выхода связей** (сверху, снизу, слева, справа) с автоматическим выбором оптимального порта.
- **3 типа линий:** Ортогональные (углы), Кривые (Безье), Прямые.
- **Ручная корректировка линий:** потяните за маркер на линии, чтобы изогнуть ее и обойти пересечения.
- Добавление, удаление, редактирование таблиц и колонок, настройка PK/FK.

### 🔍 Анализ и генерация
- **Анализатор коллизий** — проверка на 5 типов ошибок (отсутствие PK, несовпадение типов, разная длина VARCHAR, циклы, висячие FK).
- **Генератор тестовых данных** — INSERT-скрипты с умной генерацией значений (учитываются связи PK/FK).
- **SQL Helper** — шаблоны типовых запросов (JOIN, агрегации, поиск дубликатов) на основе текущей модели.

### 📤 Экспорт
- **DDL** — CREATE TABLE скрипты.
- **S2T** — текстовое описание модели.
- **AI Prompt** — структурированный промпт для генерации ETL/DML.
- **Excel** — единый файл со всеми таблицами.
- **PNG** — экспорт текущей диаграммы в высоком разрешении (с авторасчетом границ).

### 💾 Сохранение
- Автосохранение в `localStorage` браузера (включая независимые раскладки всех вкладок).
- Восстановление при следующем открытии.

## Форматы файлов

### S2T (.s2t / .txt)

```text
Table: Customers
  ID: int PK
  Name: varchar(100)
  Segment: varchar(50)

Table: Orders
  ID: int PK
  CustomerID: int FK -> Customers.ID
  OrderDate: date
  Amount: decimal(10,2)
```

**Правила:**
- `Table: Имя` — начало новой таблицы
- `Отступ + Колонка: Тип` — колонка
- `PK` — первичный ключ
- `FK -> Таблица.Колонка` — внешний ключ

### Excel (.xlsx)

**Формат 1: Все таблицы на одном листе** (рекомендуемый)

| Table | Column Name | Data Type | Key | References |
|-------|-------------|-----------|-----|------------|
| Customers | ID | int | PK | |
| Orders | CustomerID | int | FK | Customers.ID |

**Формат 2: Один лист = одна таблица**

Лист `Customers`:

| Column Name | Data Type | Key | References |
|-------------|-----------|-----|------------|
| ID | int | PK | |
| Name | varchar(100) | | |

### CSV (.csv)

```csv
Table,Column Name,Data Type,Key,References
Customers,ID,int,PK,
Customers,Name,varchar(100),,
Orders,ID,int,PK,
Orders,CustomerID,int,FK,Customers.ID
```

## Быстрый старт

1. Откройте [демо](https://kitaevalexey.github.io/data-model-canvas).
2. Нажмите **«Загрузить пример модели»** для просмотра демо-модели (звездная схема).
3. Или **«Импорт»** → выберите ваш файл.
4. Редактируйте модель на холсте (переключайте вкладки, двигайте таблицы, изгибайте линии).
5. Экспортируйте результат (DDL, S2T, Excel, PNG или AI-промпт).
